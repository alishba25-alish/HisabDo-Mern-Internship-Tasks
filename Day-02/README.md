# Day 02: Student Management Dashboard

A modern, dynamic, and responsive Student Management dashboard created using HTML, CSS3, and JavaScript.

## Features

- **Dynamic Student Display:** Renders a list of students with auto-generated UI avatars, emails, courses, and marks.
- **Add New Student:** Interactive modal form to easily add new student records into the dynamic data store.
- **Search by Name:** Real-time search filter functionality to find students by their names.
- **Filter by Marks:** Dynamic numeric filter to list students scoring above a specified minimum marks threshold.
- **Live Counter & Metrics:** Automatically tracks and displays the total count of students currently visible.

## Tech Stack

- **HTML:** Semantic structural layout and modal setup.
- **CSS3:** Custom styles, Flexbox layout, CSS Variables, and responsive design components.
- **JavaScript:** Dynamic DOM manipulation, array filtering (`.filter()`), event handling, and array operations.
- **Font Awesome & Google Fonts:** Clean icon set and modern Inter typography.
